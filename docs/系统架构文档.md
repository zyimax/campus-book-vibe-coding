# 校园二手书交易平台 - 系统架构文档

## 1. 系统概述

校园二手书交易平台采用前后端分离架构，前端使用React框架，后端使用Java Spring Boot框架，数据库使用MySQL。

### 3.2 表结构说明

#### 用户表 (user)
- 存储用户基本信息
- 密码使用BCrypt加密存储
- 支持邮箱和手机号注册

#### 书籍表 (book)
- 存储书籍信息
- 支持多图片存储（JSON格式）
- 记录浏览量用于推荐算法

#### 订单表 (order_table)
- 存储订单信息
- 订单状态流转：待付款→待发货→待收货→已完成
- 支持订单取消

#### 地址表 (address)
- 存储用户收货地址
- 支持设置默认地址

## 4. API设计

### 4.1 RESTful规范

- 使用HTTP动词表示操作类型
- 使用名词表示资源
- 使用复数形式表示资源集合
- 使用HTTP状态码表示响应状态

### 4.2 统一响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

### 4.3 认证机制

- 使用JWT进行无状态认证
- Token在请求头中传递：`Authorization: Bearer {token}`
- Token有效期：24小时

## 5. 安全设计

### 5.1 前端安全
- XSS防护：React自动转义
- CSRF防护：使用JWT无状态认证
- 敏感信息不存储在localStorage

### 5.2 后端安全
- 密码加密：BCrypt
- SQL注入防护：MyBatis Plus参数化查询
- JWT认证：Spring Security + JWT
- CORS配置：限制允许的域名
