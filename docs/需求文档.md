## 7. 数据模型（v1.0）

### 7.1 用户表 (User)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer | 主键 |
| username | String | 用户名（邮箱/手机） |
| password | String | 密码（加密） |
| nickname | String | 昵称 |
| avatar | String | 头像URL |
| phone | String | 手机号 |
| email | String | 邮箱 |
| created_at | DateTime | 注册时间 |

### 7.2 书籍表 (Book)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer | 主键 |
| title | String | 书名 |
| author | String | 作者 |
| isbn | String | ISBN |
| category | String | 分类 |
| condition | String | 成色 |
| price | Float | 价格 |
| description | String | 描述 |
| stock | Integer | 库存 |
| delivery_type | String | 交易方式 |
| images | String | 图片JSON |
| user_id | Integer | 卖家ID |
| status | Integer | 状态（1:上架 0:下架） |
| view_count | Integer | 浏览量 |
| created_at | DateTime | 发布时间 |

### 7.3 订单表 (Order)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer | 主键 |
| order_no | String | 订单号 |
| user_id | Integer | 买家ID |
| book_id | Integer | 书籍ID |
| address_id | Integer | 收货地址ID |
| total_price | Float | 总价 |
| status | Integer | 订单状态（0:待付款 1:待发货 2:待收货 3:已完成 4:已取消） |
| created_at | DateTime | 创建时间 |
| updated_at | DateTime | 更新时间 |

### 7.4 地址表 (Address)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer | 主键 |
| user_id | Integer | 用户ID |
| receiver | String | 收货人 |
| phone | String | 电话 |
| address | String | 地址 |
| is_default | Integer | 是否默认（1:是 0:否） |

## 8. API接口（v1.0）

### 8.1 用户相关
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/user/register | 用户注册 |
| POST | /api/user/login | 用户登录 |
| GET | /api/user/profile | 获取用户信息 |
| PUT | /api/user/profile | 更新用户信息 |
| POST | /api/user/logout | 用户登出 |

### 8.2 书籍相关
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/books | 获取书籍列表 |
| GET | /api/books/:id | 获取书籍详情 |
| POST | /api/books | 发布书籍 |
| PUT | /api/books/:id | 更新书籍 |
| DELETE | /api/books/:id | 删除书籍 |
| GET | /api/books/search | 搜索书籍 |
| GET | /api/books/category/:type | 按分类获取书籍 |

### 8.3 订单相关
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/orders | 创建订单 |
| GET | /api/orders | 获取订单列表 |
| GET | /api/orders/:id | 获取订单详情 |
| PUT | /api/orders/:id/cancel | 取消订单 |
| PUT | /api/orders/:id/confirm | 确认收货 |

### 8.4 地址相关
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/addresses | 获取地址列表 |
| POST | /api/addresses | 新增地址 |
| PUT | /api/addresses/:id | 更新地址 |
| DELETE | /api/addresses/:id | 删除地址 |
| PUT | /api/addresses/:id/default | 设置默认地址 |

## 11. 风险评估

### 11.1 技术风险
- **风险**：技术选型不当
- **应对**：充分调研，选择成熟稳定的技术栈

- **风险**：性能瓶颈
- **应对**：进行性能测试，优化数据库查询和前端渲染

- **风险**：安全漏洞
- **应对**：定期安全审计，及时修复漏洞

### 11.2 业务风险
- **风险**：用户活跃度低
- **应对**：加强运营推广，提供优质内容和服务

- **风险**：交易纠纷处理
- **应对**：建立完善的纠纷处理机制

- **风险**：版权问题
- **应对**：加强内容审核，建立版权保护机制

### 11.3 运营风险
- **风险**：推广困难
- **应对**：多渠道推广，与学校合作

- **风险**：竞争激烈
- **应对**：差异化竞争，提供更好的用户体验

- **风险**：维护成本高
- **应对**：建立自动化运维体系
